Исходные материалы задания и подозрительные HTML/JavaScript-файлы в репозиторий не включены. Для запуска решений нужны исходные файлы из задания: для задания 5 — domains.txt рядом со скриптом, для задания 6 — папка 2 рядом с decode.py. Скрипт задания 6 декодирует текст, не исполняет полученный JavaScript и не обращается к найденным адресам.
